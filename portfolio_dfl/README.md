# 调仓问题的可微优化层：LP 与 QP（Alt-Diff / cvxpylayers）

## 问题

每个交易日求解

```
max_w  c'w - kappa'|w|  [- 0.5 * sum_i eta_i * w_i^2]
s.t.   sum(w) = 0,  lo <= w <= up,        c = X theta
```

- `X`：当日 n 只股票的 k 个因子；`theta`：线性收益模型的权重；`c`：预测收益率。
- `w`：调仓量，可正可负；`kappa`：比例交易成本。
- 不含方括号那一项时是 LP，含（`eta > 0`）时是 QP。

训练目标是端到端学习 `theta`（decision-focused learning）：
- 损失为 `-(r'w - kappa'|w|)`，即实现收益扣除比例成本，与原问题的语义一致；
- `r` 是实现收益。

## 模拟数据（`problem.make_data`，默认参数）

- **规模**：3000 只股票，5 个因子，每个交易日的截面独立生成。
- **单因子 IC**：从 U(0.04, 0.08) 中抽取。
- **因子相关性**：因子两两等相关，相关系数由"合成信号 IC = 0.10"反解得到。
- **真实 alpha**：为 `X theta*`，取 `theta* = ret_vol * S^-1 ic`。这样每个因子的 IC 等于设定值，`X theta*` 的 IC 为 0.10。
- **收益与成本**：
  - 收益的截面波动为 2%，因此 alpha 的截面离散度为 20bp；
  - 比例成本为 5–20bp；
  - 单只股票的调仓上下限为 NAV 的 ±5–15bp。
- **本次实现值**（500 天的均值）：单因子 Pearson IC 为 0.042–0.074，合成信号 IC 为 0.101（rank IC 为 0.097）。
- **关于 IC 的取值**：如果单因子 IC 按字面取 0.6，合成 IC 就不可能只有 0.10，因为最优合成的 IC 不会低于最好的单因子。所以这里按 0.06 左右处理。
- **可调参数**：`ic_single`、`ic_combined`、`ret_vol`、`limit_bp`、`cost_bp`、`k`。

## 文件

| 文件 | 内容 |
|---|---|
| `problem.py` | 按 IC 标定的数据生成和 IC 计算；精确 LP（向量化的断点扫描，没有求解器容差）；QP 的闭式解和解析雅可比；cvxpylayers 层 |
| `altdiff.py` | Alt-Diff 的两个版本：<br>• `altdiff_qp`：通用的稠密版；<br>• `altdiff_box`：利用"盒约束 + 一个预算约束"的结构，Hessian 为对角加秩一，用 Sherman–Morrison 求逆。<br>两者的迭代完全相同（已核对到 1e-12），但 `altdiff_box` 每步只需 O(n)，n=3000 时只有它可用。两者都在前向模式下直接对 `theta` 求切向量（k 列） |
| `run_lp.py` / `run_qp.py` / `run_surrogate.py` | 测试 1–3 |
| `run_why.py` | 测试 4：拆解端到端训练没赢的原因 |

两处精确改写，都不改变问题语义：

1. `|w|`：拆成 `w = p - m`，其中 `p, m >= 0`。
2. 二次项：在拆分变量上写成 `0.5*eta*(p^2 + m^2)`。
   - 因为 `kappa > 0`，最优解一定满足 `p_i * m_i = 0`，所以这一项等于 `0.5*eta*w^2`。
   - 这样 `P = diag(eta, eta)` 严格正定。

## 结论（n=3000，合成信号 IC 0.10）

1. **LP 能求解，但无法端到端训练。**
   - 精确 LP 解里，54% 的仓位在上下限，46% 为 0，每天只有 1 只股票用来补齐预算。梯度处处为 0，有限差分结果恰好为 0。
   - **cvxpylayers**：
     - 默认精度下决策误差达 1.3e-3，和调仓限额同一量级；收紧后为 5e-9。
     - 两种精度下的梯度都只有约 1e-4，而 QP 的梯度约为 23。
     - 训练 10 步没有任何进展，`theta` 只有 2% 的随机漂移。
   - **Alt-Diff**：
     - 在 LP 上跑 2 万步仍未收敛（误差 2.9e-5），这时的"梯度"范数为 110，是未收敛造成的。
     - 截断在 100 步的版本在训练中确实学到了方向（余弦 0.982，测试净收益 20.14bp/日），但 `theta` 的尺度被推大到 1.33 倍，平滑程度也没法控制。
2. **QP 下两者都能用，训练轨迹一致。**
   - 与闭式解的轨迹相比，Alt-Diff 训练 60 步后的 `theta` 相差 9e-9，cvxpylayers 训练 5 步后相差 4e-8。
   - **cvxpylayers**：
     - 必须收紧精度，默认精度下梯度误差为 4.2%；
     - n=3000 时每步（32 个交易日）要 48 秒。
   - **Alt-Diff**：
     - 必须用结构化实现 `altdiff_box`，`rho` 取 eta 到 3·eta 之间（实测 `eta=0.1` 时 0.3 最快，`eta=0.3`、`eta=1` 时 1 最快）；
     - 每步 3.3 秒，比 cvxpylayers 快约 15 倍；
     - `rho` 偏离合适值 10 倍，会慢约 4.5 倍。
   - **闭式解**：每步 0.1 秒，比 Alt-Diff 再快约 30 倍，而且是精确的。
   - qpth 和仓库原版的 `classification/newlayer.py` 在 n=3000 下都不可行，因为每个交易日都要处理稠密的 6000 维系统。
3. **二次项的系数 `eta` 在这组数据上取 0.1 左右最合适。**
   - 此时：
     - 3.3% 的仓位与 LP 不同；
     - LP 目标每天只损失 0.02bp（LP 的预测目标值为 20.5bp/日）；
     - 每天约有 96 个自由仓位提供梯度。
   - 从随机初始值训练 300 步，测试净收益 21.03bp/日，IC 0.100，`theta` 尺度为 1.02 倍，与 OLS（20.99）和真值（21.09）基本一样。
   - `eta` 过大的代价：`theta` 被推得更大（`eta=0.3` 时 1.24 倍，`eta=1` 时 1.58 倍），部署 LP 时交易过度，测试净收益降到 20.60 和 19.53bp/日。
   - `eta` 过小的代价：梯度又稀又尖。`eta=0.01` 时每天只有约 11 个自由仓位，梯度范数达 176。
   - 经验上，"`eta` × 单票限额"取 alpha 截面离散度的 1/20 左右合适，这里是 `0.1 × 10bp = 1bp`，对比 20bp。
4. **端到端训练与两阶段 OLS 的对比。**
   - 3000 只股票 × 250 天的数据量下，OLS 已经把方向学到真值（余弦 1.000，IC 0.101），端到端训练带不来额外收益。
   - 从 OLS 出发再微调，只会让尺度变大，测试净收益从 20.99 降到 19.7–20.9。
   - 两者的差别要在真实数据上才可能出现（模型有偏、非线性、厚尾），需要和两阶段基线对比。原因拆解见下一节。

## 端到端训练为什么没赢过两阶段（`run_why.py`）

本节的收益都是期望日净收益（bp），用真实的条件均值 `E[r|X]` 计算，不含实现噪声。

**原因 1：模型设定正确时，两阶段本身就是决策最优的。**
- 目标 `r'w - kappa'|w|` 对 `r` 是线性的，约束里也没有 `r`。所以给定 `X`，期望目标就是 `E[r|X]'w - kappa'|w|`，把真实的条件均值代入 LP，得到的就是最优决策。
- 这里 `E[r|X] = X theta*` 恰好在线性模型的范围内，于是均方误差最优和决策最优指向同一个 `theta*`。
- 端到端训练没有偏差可以纠正，只能比估计精度，而高斯噪声下 OLS 就是最有效的估计。
- 理论依据：
  - Elmachtoub, Lam, Zhang, Zhao (2023, arXiv:2304.06833) 证明，模型设定正确且数据充足时，"先估计再优化"的后悔值随机占优于端到端方法；设定有偏时结论反转。
  - Hu, Kallus, Mao (2022, Management Science) 证明，直接代入预测值的做法，后悔值收敛更快。

**原因 2：训练用的 QP 与部署用的 LP，最优参数不同（E1）。**

| 策略 | 最优尺度 a（θ = a·θ*） | 端到端学到的尺度 | 按该策略部署：OLS / 端到端 | 按 LP 部署：OLS / 端到端 |
|---|---|---|---|---|
| LP | 1.0 | — | 20.53 / — | 20.53 / — |
| QP `eta=0.1` | 1.0 | 1.08 | 20.49 / 20.47 | 20.53 / 20.44 |
| QP `eta=0.3` | 1.15 | 1.18 | 20.30 / 20.35 | 20.53 / 20.25 |
| QP `eta=1` | 1.5 | 1.52 | 18.68 / 20.13 | 20.53 / 19.52 |

- 为什么两者的最优尺度不同：
  - QP 会让阈值附近的股票只拿部分仓位，最好的应对是把 `c` 放大；
  - LP 本来就是满仓或零仓，放大 `c` 只会把净 alpha 为负的边缘股票也拉进来。
- 端到端训练学到的尺度，正好是它所训练的那个 QP 的最优尺度：
  - 按 QP 部署时，它胜过 OLS（`eta=1` 时每天多 1.45bp）；
  - 换成 LP 部署就输了。

**原因 3：统计效率低，而且会拟合噪声（E2，8 个互不重叠的 40 天样本，`eta=0.1`）。**

| | OLS | 端到端 |
|---|---|---|
| 方向误差 | 5.0° ± 1.4° | 8.3° ± 2.8° |
| 期望测试 LP 收益 | 20.46 ± 0.05 | 20.26 ± 0.17（8 个里输了 7 个） |
| 样本内实现目标（端到端直接优化的量） | 20.01 | 20.79 |

- 梯度只经过阈值附近的"自由"仓位，只占全部"股票-日"样本的 3.2%，而 OLS 用了 100%。在线性模型下，远离阈值的股票同样包含 `theta` 的信息，端到端训练把它们丢掉了。
- IC 0.1 时信噪比很低。端到端训练把样本内的实现收益推高了 0.8bp，样本外反而更差，这是典型的"优化者诅咒"。

**什么时候端到端训练会赢：模型设定有偏，而且这种偏差和交易有关（E3，4 个独立的 250 天样本）。**

| 真实 alpha | OLS | 端到端 | 端到端 − OLS（每个样本） |
|---|---|---|---|
| A：最强因子在低成本股票上方向相反（−1 倍），在高成本股票上为 +3 倍，平均效应不变 | 16.54 | 17.45 | +1.10, +0.82, +0.78, +0.93 |
| B：alpha 在尾部饱和，`12bp·tanh(z/12bp)` | 1.51 | 1.43 | −0.15, −0.10, −0.04, −0.03 |

- **场景 A**：OLS 拟合的是全体股票的平均效应。但真正会被交易的主要是门槛低的低成本股票，端到端训练把权重调向了在这些股票上有效的因子。
- **场景 B**：偏差存在，但任何线性的 `theta` 都改善不了决策（最优的线性策略和 OLS 差不多），于是只剩方差带来的代价。
- 所以，模型有偏只是端到端训练胜出的必要条件，不是充分条件。
