# 调仓问题的可微优化层：LP 与 QP（Alt-Diff / cvxpylayers）

## 问题

每个交易日求解

```
max_w  c'w - kappa'|w|  [- 0.5 * sum_i eta_i * w_i^2]
s.t.   sum(w) = 0,  lo <= w <= up,        c = X theta
```

- `X`：当日 n 只股票的 k 个因子；`theta`：线性收益模型的权重；`c`：预测收益率。
- `w`：调仓量，可正可负；`kappa`：比例交易成本。
- 不含方括号那一项时是 LP，含（`eta > 0`）时是 QP。

训练目标是端到端学习 `theta`（decision-focused learning）：
- 损失为 `-(r'w - kappa'|w|)`，即实现收益扣除比例成本，与原问题的语义一致；
- `r` 是实现收益。

## 运行

```sh
cd portfolio_dfl
pip install -r requirements.txt
python run_lp.py          # 测试 1：LP
python run_qp.py          # 测试 2：QP
python run_surrogate.py   # 测试 3：用 QP 替代 LP 后的语义变化，以及端到端训练
```

合成数据的设定：
- 规模：n=50 只股票，k=5 个因子；
- 信号与噪声：预测 alpha 的截面标准差约 30bp，日收益噪声 2%；
- 成本与限额：kappa 为 5–20bp，单只股票的调仓上下限在 ±1% 到 ±3% 之间。

## 文件

| 文件 | 内容 |
|---|---|
| `problem.py` | 数据生成；精确 LP（沿断点扫描，没有求解器容差）；QP 的闭式解和解析雅可比；cvxpylayers 层 |
| `altdiff.py` | 修正后的批量 Alt-Diff：前向模式直接对 `theta` 求切向量（k 列），用原始/对偶残差判停，`rho` 可调 |
| `run_lp.py` / `run_qp.py` / `run_surrogate.py` | 三组测试 |

两处精确改写，都不改变问题语义：

1. `|w|`：拆成 `w = p - m`，其中 `p, m >= 0`。
2. 二次项：在拆分变量上写成 `0.5*eta*(p^2 + m^2)`。
   - 因为 `kappa > 0`，最优解一定满足 `p_i * m_i = 0`，所以这一项等于 `0.5*eta*w^2`。
   - 这样 `P = diag(eta, eta)` 严格正定，Alt-Diff 和 qpth 都可以直接用。

## 结论

1. **LP 可以求解，但无法端到端训练。**
   - 精确 LP 解里，66% 的仓位在上下限，32% 为 0，每天只有 1 只股票处在中间（用来补齐 `sum(w)=0`）。
   - `theta` 的微小变动不会改变这个结构，所以实现收益对 `theta` 的梯度处处为 0（有限差分结果恰好为 0）。
   - 所有非零"梯度"都来自不精确求解：
     - cvxpylayers 用默认 SCS 精度时，梯度范数达 970，却只带来很小的改进；
     - 截断的 Alt-Diff 相当于一种隐式平滑，确实能学到方向，但平滑程度由步数和 `rho` 隐式决定，没法控制。
2. **QP 下 Alt-Diff 和 cvxpylayers 都能用，结果一致。**
   - 两者训练 60 步后的 `theta`，与闭式解的训练轨迹相比，差别分别为 5e-9 和 2e-3。
   - 前提一：cvxpylayers 必须收紧 SCS 精度（`eps=1e-8`），默认精度的梯度误差有 2%–8%。
   - 前提二：Alt-Diff 必须用修正后的实现（本目录的 `altdiff.py`）。仓库原版 `classification/newlayer.py` 在这个问题上的梯度误差是 25%，主要原因是它的停止准则（目标函数相对变化小于 1e-3 就停）；`rho=1` 在修正版里仍然准确，只是收敛慢了约 4 倍。
   - 这个问题本身有闭式解（一维求乘子），比两者快 1–2 个数量级；n=500 时快 100 倍以上。
3. **"不改变语义"的边界。**
   - 拆分变量、`0.5*eta*(p^2+m^2)` 这两步是精确改写，完全不改变语义。
   - 但只要加入二次项，决策映射就一定会变。`eta=1e-4` 时，98% 的交易日决策与 LP 完全相同，但这些天的梯度恰好为 0，其余天的梯度又极大。"决策完全不变"和"有可用的梯度"不可兼得。
   - 在本数据的尺度下，`eta` 取 0.01–0.03 是合适区间：
     - LP 目标每天只损失 0.02–0.17bp（每日净收益为 13.4bp）；
     - 91%–100% 的交易日梯度非零。
   - 合适的量级取决于 `eta × 单票限额` 与 alpha 截面离散度之比。
4. **用 QP 代理训练、部署回 LP 时，要控制 `c` 的尺度。**
   - 训练会把 `|theta|` 推大到 1.2–3.5 倍，`eta` 越大越明显：模型在用更大的 `c` 抵消平滑。
   - 部署 LP 时，`c` 相对 `kappa` 的尺度直接决定交易量。
   - 可行的做法有三种：
     - 用独立验证集选缩放系数。本实验用训练集来选，效果不稳定。
     - 把 `c` 做截面标准化后只学方向。
     - 把二次项当作真实的冲击成本（例如 `eta_i` 按 `sigma_i / ADV_i` 标定），训练和部署都用 QP，从根本上避免错配。
5. **端到端训练本身不一定优于两阶段。**
   - 在这份设定正确（线性、高斯）的合成数据上，端到端训练的测试净收益为 11.3–12.4bp，没有超过 OLS 的 12.7bp。
   - 从 OLS 出发再微调，测试结果反而下降，同时 `|theta|` 被推大。
   - 它的价值在于模型设定与决策不匹配的情形，实盘数据上需要和两阶段基线对比验证。

## 结果

### 测试 1：LP（`run_lp.py`，64 天 × 50 只股票）

梯度真值为 0。作为量级参考，`eta=0.1` 的 QP 在同一数据上的梯度范数是 27。

| 层 | 用时 | max\|w−w*\| | 梯度范数 |
|---|---|---|---|
| cvxpylayers，SCS 默认精度 | 0.30s | 1.8e-2 | 970 |
| cvxpylayers，SCS `eps=1e-8` | 0.32s | 1.3e-8 | 1.3e-6 |
| Alt-Diff `rho=0.1`，跑到收敛（约 6500 步） | 12.3s | 8.7e-9 | 4.1e-2 |
| Alt-Diff `rho=0.01`，跑到收敛 | 9.9s | 9.1e-9 | 2.5e-4 |
| Alt-Diff `rho=0.1`，截断在 100 步 | 0.19s | 1.4e-2 | 210 |
| Alt-Diff `rho=0.1`，截断在 1000 步 | 1.9s | 7.7e-3 | 390 |
| 仓库原版 `classification/newlayer.py` | 4.2s | 2.0e-2 | 20 |

Alt-Diff 的切向量是对 `theta` 求的，只有 k 列。它慢的部分在于稠密的 `2n×2n` 矩阵运算。n 到几千时，需要利用 `G=[I;-I]` 和"对角 + 秩一"的 Hessian 结构，把每步开销降到 O(n)。

脚本还会输出"按训练集选缩放系数后再部署 LP"的结果。它的效果不稳定：
- 有时有帮助，例如 `eta=0.3` 时从 11.29 升到 12.33；
- 有时反而有害，例如 `eta=0.01` 时从 12.36 降到 12.06，真值 θ* 本身也会从 13.41 降到 12.90。

因此缩放系数应该用独立的验证集来选。

## 备注

- ECOS 在当前 scipy 版本下调用失败（`csc_array` 没有 `get_shape` 方法），所以 cvxpylayers 统一用 SCS。
- 所有数字都来自固定随机种子，重复运行结果完全一致。
